# Contributing

- if you created any textures, you can submit them either using a pull request or send them to me on discord via **@possible_triangle**
- pull requests are welcome to any of the main branches, if you modified any code, please run `spotlessApply` before opening one to format the code.
- non-texture assets & data is almost entirely generated using data generators, if you submit any new code, it should also make use of them.
- contributors are listed on the projects README file listing which parts they have worked on.
